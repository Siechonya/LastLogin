# 最后一次登录 · The Last Login

一款**可独立运行的浏览器叙事解谜游戏**。你收到一位失踪三个月的大学好友寄来的旧笔记本电脑——
准确地说，是她的母亲按她留下的字条寄给你的。

登录这台电脑，翻看她留下的文件、邮件、聊天、照片、浏览历史与系统日志，
还原 2026 年 6 月 11 日深夜之后究竟发生了什么。

- 游玩时长：**30–60 分钟**
- 全部内容**预先生成**：运行时不联网、不调用任何模型、不需要 API key
- 三条相互交织的线索链、两次有伏笔的反转、一个可以用证据支撑的最终答案
- 完整桌面环境：窗口管理、文件系统、全局搜索、线索收藏、分级提示、推理结案、本地存档

> ⚠ **剧透警告**：`docs/WALKTHROUGH.md` 是完整通关攻略，包含全部真相与密码。第一次游玩请不要打开。
> 本游戏所有人物、公司、案件、网页与聊天记录均为虚构。

## 快速开始

### 方式一：直接双击（最简单）

双击项目根目录下的 **`index.html`**，用 Chrome / Edge 打开即可游玩。

> 浏览器本地存档在 `file://` 下依然可用；若你的浏览器禁用了 file:// 存储，游戏会提示你改用「导出存档」。

### 方式二：本地服务器（推荐，最接近真实环境）

```bash
# 用自带的零依赖服务器（需要 Node.js）
node tools/serve.js
# 然后浏览器打开 http://127.0.0.1:8765/

# 或者用 Python
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

### 系统要求

- 现代桌面浏览器：Chrome / Edge 90+（推荐 1440×900 以上窗口）
- 无需安装任何依赖，无需联网

## 怎么玩

| 操作 | 说明 |
|---|---|
| 单击桌面图标 | 打开对应应用 |
| 窗口标题栏拖拽 | 移动窗口；双击标题栏最大化 |
| 窗口右下角 | 拖拽缩放 |
| 任务栏按钮 | 切换 / 最小化窗口 |
| **Ctrl + K** | 全局搜索这台电脑（文件、邮件、聊天、照片、网页、日志、备忘录） |
| ☆ 收藏为线索 | 在证据页面点击，收进「调查手册」的线索板 |
| 左下角 ★ 按钮 | 系统菜单：存档管理、关于本机、重新开始 |

### 核心流程

1. **登录**：开场读完妈妈寄来的信与便利贴，按提示输入开机密码。
2. **搜证**：在 9 个应用里翻找。有些文件夹、相簿、压缩包是加密的——密码都藏在她留下的内容里。
3. **收藏线索**：17 枚关键线索会自动归类到三条线（工作线 / 人际线 / 失踪线）。
4. **结案**：在「调查手册 → 结案」回答三个问题。答案错了会得到方向性反馈，不会直接告诉你答案。
5. **最后一步**：结案成立后，`下载/starfall.zip` 才能打开。里面有她留给你的信。

### 提示系统

「调查手册 → 提示」提供 10 组分级提示：

- **第 1 级**只给方向，不含任何结论；
- **第 2 级**指向具体证据载体；
- **第 3 级**直接给出结论或密码（有剧透确认框）。

每查看一级新提示都会记录一次「提示使用」，影响最终评价（S/A/B/C），但**不影响通关**。

### 存档

- 自动保存：每次收藏线索、解锁、查看提示、提交推理都会写入浏览器本地存储。
- 手动槽位：系统菜单 → 存档管理 → 3 个槽位（保存/读取/删除）。
- 导出/导入：存档管理里可导出 `last-login-save.json`，换机器或换浏览器时导入即可续玩。
- 关掉标签页不会丢进度；「重新开始」会清空自动存档（手动槽位保留）。

## 项目结构

```
index.html                 游戏入口（双击即玩）
css/main.css               全部样式（深夜书桌风格）
js/core/                   引擎：db 数据索引 / state 存档 / ui 组件 / wm 窗口管理
                                 search 全局搜索 / boot 开场与桌面 / ending 结局 / main 入口
js/apps/                   应用：files mail chat photos browser calendar logs notes investigate
js/data/                   内容（全部预生成，无运行时生成）
  00_meta.js                 锁/17 枚线索/分级提示/推理题/开场/结局
  11_files_work.js           工作线文件        13_files_missing.js  失踪线文件与回收站
  20_emails.js               邮件 19 封        30_chats.js          聊天 7 个会话
  40_photos.js               照片 15 张        50_browser.js        网页快照/历史/书签
  60_misc.js                 日历/系统日志/备忘录
assets/photos/             15 张手绘风 SVG 照片（含 3 张「文档型照片」）
assets/avatars/            10 个 SVG 头像
docs/STORY_BIBLE.md        故事圣经：真实事件时间线、反转与伏笔登记、密码表（剧透）
docs/CONTENT_SPEC.md       数据 schema 与全部内容槽位清单
docs/WALKTHROUGH.md        完整通关攻略（剧透）
tools/serve.js             零依赖本地服务器
tools/validate.js          内容一致性自动验证（日期/人名/密码/线索可达性/提示不泄底）
tools/playthrough.js       浏览器自动化：完整通关 + 全量条目渲染扫描
tools/smoke.js             file:// 协议冒烟测试
```

## 开发者命令

```bash
node tools/validate.js      # 内容一致性验证（158 项检查，失败退出码 1）
node tools/serve.js &       # 启动本地服务器
node tools/playthrough.js   # 自动化通关 + 364 条目渲染扫描（需本机 Chrome/Edge 与 tools 下 npm i）
node tools/smoke.js --file  # file:// 协议下的冒烟测试
bash tools/check-all.sh     # 一键：验证 → http 通关 → file:// 冒烟
node tools/wordcount.js     # 内容体量统计（约 2.9 万汉字 / 387 条目）
node tools/svgshot.js       # 把 25 个 SVG 资产渲染成预览图供目检
```

`tools/` 下的测试依赖 `puppeteer-core`（已在 `tools/package.json`，`cd tools && npm i` 安装），
驱动本机已装的 Chrome 或 Edge，不会下载浏览器。

## 故障排查

| 现象 | 处理 |
|---|---|
| 双击 index.html 后黑屏 | 打开浏览器控制台（F12）看报错；确认 `js/data/` 下 8 个文件齐全；或改用 `node tools/serve.js` |
| 提示「此浏览器禁用了本地存储」 | 用方式二的本地服务器打开；或定期「导出存档」 |
| 照片显示空白 | 确认 `assets/photos/*.svg` 存在（15 个文件） |
| 忘记密码 | 锁屏点「忘记密码？」，或在「调查手册 → 提示」查看对应分组；答案见 `docs/WALKTHROUGH.md` |
| 想重玩 | 左下角 ★ → 重新开始 |
